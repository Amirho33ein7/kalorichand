چی خوردی؟

می‌توانید مقدار را هم بنویسید؛ قبل از ثبت نهایی می‌توانید آن را تأیید یا اصلاح کنید.
پوشش جست‌وجو فقط محدود به فهرست داخلی نیست؛ غذاهای ناشناخته، محصولات برنددار و بسیاری از غذاهای خارجی از منابع آنلاین هم جست‌وجو می‌شوند.
غذا یا خوراکی در دیتابیس پیدا نشد؟ نامش را بنویس و مقدار کالری را خودت وارد کن؛ این عدد مستقیماً به مصرف کالری امروز اضافه می‌شود.
ثبت دستی فقط کالری را وارد می‌کند و چون اطلاعات ماکرو نداریم، پروتئین، کربوهیدرات و چربی آن صفر می‌ماند.

این عدد یک برآورد اولیه است، نه یک نسخه پزشکی یا درمانی.

هوش غذایی و جست‌وجوی آنلاین

برای تشخیص طبیعی عبارت‌هایی مثل «دو تخم‌مرغ آب‌پز» و پیدا کردن محصولات برنددار، اپ ابتدا دیتابیس داخلی و سپس منابع آنلاین را بررسی می‌کند. برای تحلیل هوشمندتر می‌توانید کلید OpenAI خودتان را وارد کنید؛ این کلید فقط در مرورگر همین دستگاه نگه‌داری می‌شود؛ برای انتشار عمومی اپ، استفاده از یک سرور واسط امن توصیه می‌شود.

مرکز API

نسخه عمومی بدون کلید هم کار می‌کند: دیتابیس داخلی + موتور جست‌وجوی فازی + Open Food Facts. برای AI در نسخه عمومی، Proxy امن وارد کنید؛ کلید مستقیم OpenAI فقط برای استفاده شخصی همین دستگاه است و نباید داخل GitHub یا فایل عمومی قرار بگیرد.
