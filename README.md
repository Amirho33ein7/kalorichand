# 🍎 کالری چند

**کالری چند** یک اپلیکیشن فارسی و RTL برای ثبت و پیگیری کالری و وعده‌های غذایی روزانه است.

## امکانات
- ثبت غذای مصرف‌شده و محاسبه کالری روزانه
- جست‌وجوی غذا و محصولات غذایی
- ثبت دستی کالری برای غذاهایی که در دیتابیس پیدا نمی‌شوند
- نمایش کالری مصرف‌شده، هدف تقریبی و مقدار باقی‌مانده
- نمایش پروتئین، کربوهیدرات و چربی
- تاریخچه روزها و گزارش هر روز
- ویرایش اطلاعات پروفایل و هدف کالری
- محاسبه BMI و هدف تقریبی روزانه
- رابط کاربری فارسی، RTL و سازگار با موبایل
- انیمیشن‌ها و طراحی تیرهٔ مدرن

## فایل اصلی
نسخه فعلی به صورت یک فایل مستقل در مسیر `index.html` قرار دارد.

## اجرای نسخه وب
این پروژه یک سایت استاتیک HTML/CSS/JavaScript است. برای اجرای آن به صورت سایت، مخزن باید از طریق GitHub Pages یا یک سرویس میزبانی استاتیک منتشر شود؛ باز کردن صفحهٔ فایل در رابط GitHub فقط سورس کد را نشان می‌دهد.
